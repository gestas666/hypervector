# hypervector-tui Implementation Plan (Phase 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a read-only **Ratatui** binary `hypervector-tui` — condensed financial ops terminal (Ops Floor + Card Focus) projecting CLI/ledger truth (status, gates, KPIs, decision tape, regime), with tickrs-grade visual craft and no second strategy brain.

**Architecture:** Hybrid read model (Rust parses `decisions.jsonl` + layout mtimes; CLI subprocess or JSON fixtures for `status` / checks / report summaries / regime). Thin App loop renders floor cards or one focus view. No writes to paper/live truth; no `paper-run`/`live-run` spawn for control.

**Tech Stack:** Rust workspace crate `hypervector-tui`; Ratatui 0.30+ + crossterm; color-eyre; tui-big-text; tachyonfx (sparse); throbber-widgets-tui; termprofile; ratatui-garnish; tui-piechart and/or ratatui-stacked-bar; tui-skeleton; tui-popup; toaster; serde/serde_json; optional later Python shim.

**Spec:** `docs/superpowers/specs/2026-07-23-phase5-tui-design.md` (**Approved** by Albert 2026-07-23)

**Visual bar:** [tickrs](https://github.com/tarkah/tickrs) for series/KPI density; btop/k9s for card packing + mode visibility.

## Global Constraints

- Binary/crate name: **`hypervector-tui`** only (not “GOAT”).
- **Read-only v1:** must not start/stop daemons, arm live, place orders, or mutate policy/secrets.
- Data truth: `data/paper/`, `data/live/` under `--data-root` (default project `data/`); same CLI JSON field names as 4c.
- **Never** print secret values (wallet, API keys); presence booleans only.
- Mode banner always visible: shadow / paper / live; mainnet only.
- At most **two views:** Ops Floor + Card Focus (`Esc` back).
- Regime: display only; **must not** reimplement a divergent detector — bind to `hypervector regime` JSON / export metrics shape.
- **GUI deferred** until TUI complete + holistic review; do not implement GUI in this plan.
- Prefer branch: `feat/phase5-tui` from clean `main`.
- Do not commit `audio/`; do not push unless Albert asks.
- Offline tests must pass without network/secrets; no venue place.
