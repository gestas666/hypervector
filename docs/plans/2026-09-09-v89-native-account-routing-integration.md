## Trade-offs and failure criteria

A flat-state or fixed-rank adapter is insufficient: it misses the reproduced
occupied-slot boundary. Changing account capacity checks alone would preserve
that mismatch with native routing. The integration must select from native
routing while leaving account sizing as an additional acceptance constraint.

Any changed original input, unintended replacement entry, premature slot release,
unmatched native action, altered quote/cost, double funding, failure of atomicity,
missing terminal phase or unexplained control difference invalidates the affected
claim. The seven-slot diagnostic is reassuring only within its artificial scope;
it does not establish unchanged historical profit or correct future performance.
Rollback is to the preserved baseline research path and frozen source. Live code,
configuration, process lifecycle and deployment remain outside this plan.
